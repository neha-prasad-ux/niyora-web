# niyora-web

Marketing site for [Niyora](https://niyora.com) — a privacy-first macOS menu-bar breathing companion.

Built with [Astro](https://astro.build), deployed on Cloudflare Pages.

## Develop

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
```

Output goes to `dist/`. Cloudflare Pages auto-builds on push to `main`.

## Pages

- `/` — landing page with parallax orb that shifts color through the five Soul tiers
- `/privacy/` — privacy policy
- `/terms/` — terms of service

## App repo

The Niyora macOS app source lives at [github.com/neha-prasad-ux/niyora](https://github.com/neha-prasad-ux/niyora).
